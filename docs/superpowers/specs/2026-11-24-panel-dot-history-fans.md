# 面板历史点阵与四块概览

用户要求概览 CPU 历史从折线改为点状图，底部由三块变为四块并新增风扇转速。

## 实现

- 概览 CPU 和全部模块详情采用同一 HistoryDotChart，使用与状态栏一致的圆角小方点。概览八行、详情十六行，列数随可用宽度调整；保留 1h / 6h / 24h 和百分比固定 0–100% 量程。
- HistoryDotSeries 按固定时间段、实际时长计算平均占比。填充为平均值，淡点表示该段峰值，包含缺测或超长采样间隔的列留空。参考上限固定，不按当前负载自动缩放百分比图。
- 底部为 GPU、温度、功耗、风扇四块等宽卡片。风扇前两路分别显示实际 RPM，0 保留为真实停转读数，失效显示破折号；更多风扇通过传感器详情查看。
- 点击风扇卡片进入温度与风扇模块。没有改动采集器、用户指标选择和网络查询配置。

## 验证

- 新的历史点阵检查先因缺少 HistoryDotSeries 失败，实现后 97 项核心检查及 C decoder 检查通过；覆盖固定量程、时长加权、归档峰值、缺测、长间隔与超限值。
- 20 项隔离偏好的原生应用检查通过，Release 构建及本机签名验证通过。
- 独立代码审查未发现需要修复的重要问题。
- 已更新 `/Applications/SystemMonitor.app` 并重启；备份在 `.build/backups/SystemMonitor-before-panel-dots-fans.app`。
- CUA 实机截图确认四块概览完整显示且无额外滚动，分别显示两只风扇的实际 RPM；点击风扇进入传感器详情正常。CPU 详情已使用点阵，时间范围和逐核心数值保留。
- 重启后历史按真实采样重新积累；未填充或伪造旧数据。
