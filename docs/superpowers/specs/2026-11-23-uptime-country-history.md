# 开机时长、出口国家与 24 小时历史

## 用户需求

概览添加开机运行时间；网络处添加当前 IP 对应国家图标；所有模块历史范围改为 1h / 6h / 24h。用户明确选择并授权国内 `https://myip.ipip.net` 查询，优先直连可用。

## 实现

- BasicCollector 通过 `kern.boottime` 提供系统启动时间，概览按墙钟差计算包含睡眠的运行时长，每分钟刷新文案。
- IPIP 为可选服务，旧配置默认关闭，不进行查询；当前试用配置已通过设置按用户授权开启。仅用 HTTPS 请求取得公网出口 IP 与国家，服务不会收到监控读数。
- NWPathMonitor 在网络变化时使旧结果失效，切换采样接口与唤醒时刷新。请求异步执行，成功缓存 15 分钟，失败 60 秒后重试；有超时、取消和代次验证。暂停/睡眠时挂起查询。
- 概览网络旁显示国家旗帜，网络详情提供国家/IP与手动刷新，未知显示地球。分流 VPN 下 IPIP 所见出口可能不同于海外站点，设置中明确说明。
- 详情所有七个模块使用 1h / 6h / 24h。概览 CPU 显示最近 1 小时，菜单栏继续显示 60 秒短时历史。
- MetricHistory 默认保存 86400 秒。近期 120 秒保持原采样；更早的数据按 10 秒聚合均值及最小/最大范围。聚合保留每指标缺测，暂停/睡眠缺口留空；切换设备清理对应前缀。
- 历史绘制先分割缺口，再按保留峰谷的方式减少绘制点，并显示聚合范围。新历史从升级后开始积累，退出后清空，不伪造过去数据。

## 验证

- 原实现先复现 24 小时保留与 6 小时窗口测试失败；新增 API 测试失败后实现。
- `zsh scripts/test.sh`：90 核心检查通过，C decoder 0 failures。覆盖 86401 个一秒采样的整天回放、采样保留上限、近期精度、旧尖峰、缺测、前缀清理、绘制减点、IP/国家解析、启动时长。
- `MonitorMenuChecks`：20 项原生应用检查通过，新增真实 bootTime、隔离测试不联网检查。
- 正常网络下 IPIP 返回有效响应，实际应用已显示中国旗帜；Cloudflare 从未启用，拒绝后的端点未绕过执行。
- Release 构建/本机签名通过，更新 `/Applications/SystemMonitor.app` 前备份旧应用。
- CUA 验证概览的开机时长与国旗；逐一检查 CPU、GPU、内存、磁盘、网络、传感、功耗三个范围，实际点击 24h 与 6h 正常。

## 说明

旧历史记录没有跨进程持久化，因此不能回补升级前的 24 小时。长时历史通过整天回放测试验证；本次界面验收未等待真实 24 小时。
