# 当前菜单栏设计方向

- 常驻内容收敛为 CPU 历史曲线、内存、双行网速。
- GPU 负载暂不常驻。监控面板的 GPU 功能保留。
- 温度暂不常驻。监控面板的温度功能保留。
- CPU 保留最近 60 秒历史、固定 0–100% 纵向范围；去掉常驻 CPU、60s 标签。用户已选 B 历史点阵形式。点阵版本每列为 4 秒平均负载，整组 15 列。
- 用户在 C 点阵填充基础上确定：每个指标改为一列竖向点阵，按需选择更多指标。样例使用每列 6 格，由下向上填充；去掉 MEM 标签和常驻百分比数字。名称、时间窗口和精确数据放进悬停详情。
- 网速不使用折线图；最新规则统一为单项点阵，精确速率和单位移入悬停详情。
- CPU 与指标列共用绿 / 黄 / 红的状态语义，按各指标自身的负载或压力判定；内存颜色依据系统内存压力。CPU 历史整块按近期平均负载变色，避免逐点彩虹色；已用近期历史平均及阈值滞回抑制抖动。网速共用状态色。
- 最新样例为 menu-bar-vertical-metrics.png；两列、四列、六列示意均为可配置能力演示，不代表新增默认常驻指标。
- 已按 B 接入原生应用：历史为 15×6 点阵，实时为单列六格；两种模式分别记住逐项选择、顺序和显示类型。每个读数可独立增删，全部移除时保留应用入口。
- 根据最后统一规则，网速也改为点阵，不再常驻数值；下载、上传可分别增删，默认实时，各自可配置满格参考速率。
- `menu-bar-implemented.png` 来自生产渲染器，示例数据用于深浅外观检查。

- 最新交互：状态栏不显示悬停提示；名称和精确数据改为点击面板查看，丰富读数只保留在无障碍标签中。弹出面板已改为 480×610 的紧凑模块导航与分层概览。
