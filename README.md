# SystemMonitor

独立编写的原生 macOS 菜单栏监控工具。近期目标是替代当前机器上 iStat Menus 的核心用途，当前交付为 0.1.0 开发预览。工程没有 fork、复制或改造开源监控应用。

## 下载与安装

**[下载 SystemMonitor 0.1.0 DMG](https://github.com/Wentao-Zhao/SystemMonitor/releases/download/v0.1.0/SystemMonitor-0.1.0.dmg)** · [版本说明与校验文件](https://github.com/Wentao-Zhao/SystemMonitor/releases/tag/v0.1.0)

当前安装包适用于 **Apple Silicon（M 系列芯片），macOS 14 及以上**。这是开发预览，尚未完成所有系统和机型验收；Intel Mac 暂无安装包。

1. 下载并打开 DMG。
2. 将 `SystemMonitor.app` 拖入 `Applications`。
3. 从“应用程序”启动，菜单栏出现点阵后即可使用。

当前使用临时本机签名，尚未经过 Developer ID 公证。若首次启动被 macOS 拦截，请在“系统设置 → 隐私与安全性”查看并处理对应提示。

需要核对下载完整性时，将 DMG 和 Release 中的 `.sha256` 文件放在同一目录，运行：

```sh
shasum -a 256 -c SystemMonitor-0.1.0.dmg.sha256
```

## 当前功能

- 默认合并菜单栏，可切换为各指标独立显示；两种模式分别记住具体读数的选择、顺序、显示类型及满格参考。
- 菜单栏采用统一点阵：实时值为竖向六格，历史为最近 60 秒的横向十五列。每个具体读数均可单独添加、移除、排序；CPU 默认历史，内存和上下行默认实时。
- CPU 整机、逐核心、性能核/能效核平均负载。
- GPU 设备忙碌率。
- 内存已用/可用、压缩、缓存、交换空间和系统压力等级。
- 本地卷容量、剩余空间和对应物理设备读写速率。
- 指定网卡或自动主要网卡的上下行速率及本次应用会话流量。
- CPU/GPU 热区最高温和逐热区读数、实际风扇 RPM。
- GPU 与整机功耗；CPU 分项功耗在系统提供有效数据时显示。
- 1h/6h/24h 历史趋势，暂停/继续、1/2/5 秒基础刷新、登录时启动。

不包含电量、充电状态或手动风扇调速。监控数据留在本机；不需要账号，不上传监控数据。可选的 IPIP 出口国家查询会向 `https://myip.ipip.net` 发起 HTTPS 请求，该服务能看到请求的公网 IP，不接收 CPU、内存等监控指标。

## 已验证与未满足项

优先验证设备：Apple M1 Pro MacBook Pro、32 GB、macOS 27.2.1。工程最低部署版本是 macOS 14，不代表已经完成所有系统和机型的兼容性测试；Intel 尚未验收。

**CPU 分项功耗尚未满足完整替代要求。** 当前机器的系统 CPU 能量计数在受控负载下仍不变化。应用将其显示为不可用，不把冻结计数当作 0 W，不从整机功耗猜测 CPU 功耗。GPU 功耗与整机功耗可以独立读取。证据见 [硬件验证记录](docs/hardware-validation.md)。

温度来自芯片热区；编号不对应某一个物理核心。风扇在静止时的 0 RPM 是真实数据。整机功耗来自 SMC 传感器，既不是 CPU/GPU 分项之和，也不是插座交流电功耗。

系统内存压力显示系统提供的正常/偏高/紧张等级，不是活动监视器内存压力曲线的精确重绘。内存已用按 VM 页统计推导，扣除文件缓存与可清理页；应对齐采样时间及口径再作比较。

磁盘容量以十进制 GB/TB 显示，与 macOS 储存空间一致。可用空间采用系统提供的可回收空间估计；当前空闲空间另列，估计不可用时回退到当前空闲空间。已用空间和占用比例采用同一口径计算；APFS 共享容器的卷容量不累加。读写属于底层设备，可能包含该设备上其他卷的 I/O。网络只统计一个网卡，VPN 不与物理接口累加；流量计数在重启或切换网卡后归零。

## 安装与使用

构建产物在 `dist/SystemMonitor.app` 和 `dist/SystemMonitor-0.1.0.dmg`。打开 DMG，将 App 拖入 `/Applications` 后启动。

使用 MenuBarFold 时，请从 `/Applications/SystemMonitor.app` 启动。它所用的系统收纳机制可能隐藏从开发目录运行的应用，即使未勾选收起 SystemMonitor；这是已经在本机复现的情况。若只有设置预览、菜单栏没有入口，先确认运行位置，安装到“应用程序”后退出开发目录中的进程并重新启动。

- 左键菜单栏打开 480×610 的紧凑面板：顶部切换概览与七个模块；概览突出 CPU、内存、网络和磁盘，其他状态放在次级区域。右键可打开设置、暂停或退出。
- 概览顶部显示包含睡眠时间的开机运行时长；网络旁显示当前 IPIP 查询出口的国家旗帜，失败或关闭查询时显示地球图标。
- 设置中的“出口国家查询”可选择 IPIP（国内）或关闭。首次安装与旧配置迁移默认不联网，用户主动选择后启用；当前试用配置已按用户授权开启。网络变化与唤醒会刷新，成功结果缓存 15 分钟，失败后 1 分钟重试。网络详情可手动刷新并查看出口 IP。VPN 分流时，不同目的地可能有不同出口，IPIP 结果不代表所有网站。
- 详情保留全部读数、1h/6h/24h 历史、缺测与过期时间说明；网络历史采用柱形。最近 2 分钟保留原始采样，较早数据每 10 秒聚合平均值并保留范围，绘制时保留峰值及缺测。历史从应用运行时开始积累，退出后清除；时间范围改变不会更改 1/2/5 秒采样间隔。菜单栏继续显示 60 秒短时趋势。面板右上角可打开独立窗口或设置。
- 状态栏悬停提示已关闭；VoiceOver 仍能读取当前指标和状态。
- 首次启动展示设置；也可从设置中的“查看监控概览”打开独立窗口，在菜单栏空间不足时继续使用。重新打开 App 可找回设置窗口。
- 在设置切换合并/独立模式，用“添加指标”选择具体读数，逐项调整顺序或移除；也可从右键“菜单栏指标”快速勾选。
- 每项可选“实时点列”或“60 秒历史点阵”。网速与磁盘速率等没有自然百分比的指标提供可调满格参考，网络默认 10 MiB/s；点阵表示相对于参考值的大小，不表示链路利用率。
- 点阵由下向上填充，绿/黄/红表示状态。内存颜色依据系统压力；CPU 历史整块按近期负载变色，带阈值滞回。状态栏不显示悬停提示，点击面板查看指标名称、精确值和状态；灰色表示状态未知，斜杠表示当前不可用。
- 摘要显隐只影响菜单栏，概览与详情仍采集所有模块。全局暂停才停止采集；详情会标明保留的数据。
- 硬件最快每 2 秒读取；基础数据按所选 1/2/5 秒间隔采样；磁盘容量每 30 秒刷新。
- 不可用指标在菜单栏显示灰色斜杠；详情显示破折号，存在历史有效值时显示上次数据及时间，历史缺测处留空。
- 登录时启动默认关闭，需在设置主动开启；系统要求批准时提供登录项设置入口。

当前应用采用临时本机签名，尚无 Developer ID 签名/公证。首次打开如被系统拦截，请查看“系统设置 → 隐私与安全性”的相应提示。此开发预览没有自动更新或 App Store 分发。

## 构建与检查

需要 macOS 上的 Swift 6 工具链及 Command Line Tools。应用自身使用 Swift 5 语言模式，无第三方包依赖。

```sh
zsh scripts/test.sh
zsh scripts/test-menu-app.sh # 需正常桌面会话，使用隔离测试偏好
zsh scripts/render-menu-preview.sh
zsh scripts/package-app.sh
zsh scripts/package-dmg.sh
```

真实数据诊断（复用正式采集器，默认 3 个采样）：

```sh
CLANG_MODULE_CACHE_PATH="$PWD/.build/clang-cache" swift run --disable-sandbox \
  --cache-path .build/swift-cache --config-path .build/swift-config \
  --security-path .build/swift-security MonitorProbe 3
```

AppleSMC 与 IOReport 会受到命令执行沙盒限制。应在普通终端或正常启动的 App 中验证；不需要 sudo，不安装特权助手。第一笔速率/功耗采样只建立基线。硬件访问使用只读调用，未暴露风扇写入能力。

硬件错误类别与失败码通过本地统一日志记录，子系统为 `local.wentao.SystemMonitor`，类别为 `Hardware`。界面只展示用户可理解的状态；日志不包含流量内容、用户文件路径或上传数据。

## 工程结构

`MonitorCore` 管理模型、差分、历史和偏好；`SystemCollectors` 负责系统数据；`HardwareBridge` 隔离只读底层接口；`SystemMonitor` 负责 AppKit 菜单栏和 SwiftUI 界面。基础采集和硬件采集使用不同后台队列，主线程更新界面。

温度和功耗接口不是稳定的公开应用 API，需要按 macOS 和芯片继续验证；错误不能降级成虚构的正常数据。完整规格及实现步骤位于 `docs/superpowers/`。
